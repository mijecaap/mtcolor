# MT Color — generador de color de tienda Metin2

Página estática que genera el código `|cffRRGGBB` para colorear el nombre de una
tienda en Metin2, con vista previa y contador del límite de 30 caracteres.

- Local: `python3 -m http.server 4321`
- Deploy: app Coolify `mtcolor` (build pack dockerfile, puerto 80) → https://mtcolor.mije-dev.site/
